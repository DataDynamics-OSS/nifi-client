컨트롤러 서비스란?

컨트롤러 서비스(controller service)는 연결 풀, 레코드 리더·라이터, 인증서 설정처럼 여러 프로세서가 함께 쓰는 설정 묶음입니다. 프로세서는 속성 값으로 서비스의 id를 가리킵니다.

demo-json-reader (JsonTreeReader)  ◀── ConvertRecord.Record Reader
demo-json-writer (JsonRecordSetWriter) ◀── ConvertRecord.Record Writer

상태

  • DISABLED: 만든 직후. 설정을 고치거나 지울 수 있습니다.
  • ENABLED: 프로세서가 쓸 수 있습니다. 고치거나 지울 수 없습니다(409).
  • 참조하는 프로세서가 실행 중이면 비활성화할 수 없습니다. 먼저 프로세서를 멈추거나 updateControllerServiceReferences로 참조 컴포넌트를 한꺼번에 멈춥니다.

따라 해 보기

  1. 목록 화면에서 기본값으로 sdk-csv-reader를 만듭니다(DISABLED).
  2. 상세 화면에서 ENABLED → 설정 저장(409) → DISABLED → 저장(성공) → 삭제.
  3. 시드의 demo-json-reader에서 getControllerServiceReferences를 눌러 봅니다(참조 없음).

이 화면이 쓰는 API

List<ControllerServiceEntity> all = flow
        .getControllerServicesFromGroup("root", false, true, false, false)
        .getControllerServices();

ControllerServiceEntity s = groups.createControllerService(new ControllerServiceEntity()
        .revision(new RevisionDTO().version(0L))
        .component(new ControllerServiceDTO()
                .name("sdk-csv-reader").type("org.apache.nifi.csv.CSVReader")),
        groupId);

s = services.updateRunStatus(new ControllerServiceRunStatusEntity()
        .revision(s.getRevision())
        .state(ControllerServiceRunStatusEntity.StateEnum.ENABLED), s.getId());
