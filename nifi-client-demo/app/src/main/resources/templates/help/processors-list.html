프로세서란?

프로세서(processor)는 FlowFile(데이터 한 덩어리 + 속성)을 받아 처리한 뒤 관계(relationship) 중 하나로 내보냅니다. 예: GenerateFlowFile은 데이터를 만들어 success로, UpdateAttribute는 속성을 바꿔 success로 보냅니다.

  • 모든 관계는 다른 컴포넌트에 연결되거나 자동 종료(auto-terminate)여야 합니다. 아니면 INVALID입니다.
  • 예약 주기(scheduling period): 타이머 방식에서 몇 초마다 실행할지. 예: 5 sec, 1 min.
  • 속성 값에는 NiFi 표현식(${now()})과 파라미터(#{env})를 쓸 수 있습니다.

이 화면 사용법

  1. 기본값 그대로 createProcessor를 누릅니다. demo-flow에 sdk-generate가 생깁니다.
  2. 목록이 새로 고쳐지고, 검증이 끝나면 상태가 VALID가 됩니다(만든 직후에는 VALIDATING일 수 있음).
  3. 이름을 눌러 상세 화면에서 RUNNING → STOPPED → 삭제를 해 봅니다.
  4. 자동 종료를 비우고 만들어 보세요. INVALID가 되고, 상세 화면에 검증 오류가 보입니다.
타입 이름이 틀리면 409 "… is not known to this NiFi instance"입니다. 확장이 여러 버전이면 bundle도 지정해야 합니다.

이 화면이 쓰는 API

// 흐름 전체의 프로세서 (하위 그룹 포함)
List<ProcessorEntity> all = groups.getProcessors("root", true).getProcessors();

// 설치된 프로세서 타입
List<DocumentedTypeDTO> types = flow.getProcessorTypes(null, null, null).getProcessorTypes();

ProcessorEntity created = groups.createProcessor(new ProcessorEntity()
        .revision(new RevisionDTO().version(0L))
        .component(new ProcessorDTO()
                .name("sdk-generate")
                .type("org.apache.nifi.processors.standard.GenerateFlowFile")
                .config(new ProcessorConfigDTO()
                        .schedulingPeriod("10 sec")
                        .properties(Map.of("Custom Text", "hello"))
                        .autoTerminatedRelationships(List.of("success")))),
        groupId);
