어떻게 모으나

생성된 클라이언트는 OkHttp로 요청을 보내므로, ApiClient.getHttpClient().newBuilder()에 인터셉터를 붙여 setHttpClient로 바꿔 끼우면 모든 요청을 볼 수 있습니다. 이 앱은 두 종류를 붙입니다.

인터셉터불리는 때쓰임
애플리케이션 (addInterceptor)API 메서드 호출마다 한 번시도 번호, 연결 전에 난 실패
네트워크 (addNetworkInterceptor)서버로 나간 요청마다401 뒤 재전송까지 각각 기록, 본문·상태·시간
 
OkHttpClient http = client.getHttpClient().newBuilder()
        .addNetworkInterceptor(chain -> {
            long start = System.nanoTime();
            Response response = chain.proceed(chain.request());
            timer(chain.request().method(), response.code())
                    .record(System.nanoTime() - start, TimeUnit.NANOSECONDS);
            return response;
        })
        .build();
client.setHttpClient(http);

표 읽는 법

  • 클라이언트: nifi는 앱의 ApiClient 빈, lab-…은 장애 실험용 클라이언트입니다.
  • 시도: 같은 API 호출 안에서 몇 번째로 보낸 요청인지. 토큰이 만료되어 다시 보내면 2입니다.
  • 경로를 누르면 전체 URI와 요청·응답 본문이 펼쳐집니다. 로그인 요청의 비밀번호는 가립니다.
  • 빨간 행은 실패(4xx·5xx 또는 응답 없음)입니다.

지표

/actuator/prometheus에서 nifi_client_requests_seconds로 볼 수 있습니다. 태그는 client, method, status, outcome입니다. URI는 id가 들어가 종류가 끝없이 늘어나므로 태그로 쓰지 않습니다.
