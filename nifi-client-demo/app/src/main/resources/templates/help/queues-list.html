연결이란?

연결(connection)은 출발 컴포넌트의 관계 하나 이상을 도착 컴포넌트로 잇는 큐입니다. 도착 프로세서가 멈춰 있으면 FlowFile이 쌓이고, 배압(back pressure) 임계값(기본 10,000개 또는 1 GB)에 닿으면 출발 프로세서가 더 이상 실행되지 않습니다.

generate ─success─▶ [큐] ─▶ tag ─success─▶ [큐 쌓임] ─▶ log (정지)

상태 API 한 번으로 전체 보기

그룹마다 연결을 따로 읽는 대신 flow.getProcessGroupStatus("root", true, …) 한 번으로 모든 그룹의 큐 크기를 받습니다. 응답은 그룹마다 중첩되어 있으므로 하위 그룹(processGroupStatusSnapshots)까지 내려가며 모읍니다.

이 화면 사용법

  1. tag → log 큐가 시간이 지날수록 커지는 것을 봅니다(log가 정지 상태).
  2. 연결을 눌러 상세 화면에서 큐 목록과 FlowFile 내용을 봅니다.
  3. 연결 만들기로 generate → log를 이어 봅니다. 같은 관계를 두 연결로 보내면 FlowFile이 복제됩니다.

이 화면이 쓰는 API

ProcessGroupStatusSnapshotDTO root = flow.getProcessGroupStatus("root", true, false, null)
        .getProcessGroupStatus().getAggregateSnapshot();
for (ConnectionStatusSnapshotEntity c : root.getConnectionStatusSnapshots()) {
    System.out.println(c.getConnectionStatusSnapshot().getQueued());
}
