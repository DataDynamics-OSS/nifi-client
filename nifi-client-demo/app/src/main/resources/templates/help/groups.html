프로세스 그룹이란?

NiFi의 흐름은 프로세스 그룹(process group)의 나무입니다. 맨 위가 root 그룹이고, 보통 업무 흐름마다 하위 그룹을 하나씩 둡니다. 그룹마다 파라미터 컨텍스트를 하나 연결할 수 있습니다.

root
 └─ demo-flow   ← 시드가 만든 그룹 (demo-params 연결)
     ├─ generate ─▶ tag ─▶ log
     └─ demo-json-reader, demo-json-writer

흐름 그림

그림은 추가 호출 없이 flow.getFlow(id) 응답 하나로 그립니다.

  • 상자 위치: 각 컴포넌트의 getPosition()(NiFi UI 캔버스 좌표, 상자의 왼쪽 위). 그래서 NiFi UI와 배치가 같습니다.
  • 선: ConnectionEntity의 getSourceId() → getDestinationId(), 꺾는 점은 getBends(). 출발·도착이 하위 그룹 안의 포트이면 id가 이 그룹에 없으므로 getSourceGroupId()/getDestinationGroupId()의 그룹 상자에 붙입니다.
  • 이름표: 선택한 관계(component.selectedRelationships)와 큐(status.aggregateSnapshot.queued). 큐에 FlowFile이 있으면 노란색입니다.
  • 왼쪽 띠 색: 프로세서 component.state(초록 RUNNING, 주황 STOPPED), 검증 실패면 빨강.

Entity와 DTO

REST 응답은 대부분 XxxEntity입니다. component(DTO, 설정 본체) 바깥에 revision, permissions, status를 함께 담습니다. 목록 화면에 필요한 실행 개수·큐 크기는 ProcessGroupEntity의 runningCount, status에 이미 들어 있습니다.

revision (낙관적 잠금)

  • 만들 때는 new RevisionDTO().version(0L). 다른 값이면 400입니다.
  • 고칠 때는 지금 서버의 revision을 그대로 보냅니다. 성공하면 응답의 revision.version이 1 올라갑니다.
  • 삭제는 removeProcessGroup(id, version, clientId, null)처럼 쿼리 파라미터로 보냅니다.

이 화면 사용법

  1. 위 경로(breadcrumb)나 하위 그룹 이름으로 이동합니다. 시드의 demo-flow로 들어가 보세요.
  2. 하위 그룹 만들기 → 목록이 새로 고쳐집니다.
  3. 모두 정지 / 모두 시작으로 그룹 전체를 멈추고 켭니다. 프로세서 상태 배지가 바뀝니다.
  4. 모든 큐 비우기: 결과에 비동기 요청의 단계(만들기 → 조회 → 삭제)가 차례로 보입니다.
  5. JSON 고쳐 저장하기에서 이름이나 comments를 바꿔 저장합니다. 화면을 새로 고치지 않고 한 번 더 저장해 보세요.
실행 중인 컴포넌트나 데이터가 남은 큐가 있는 그룹은 삭제할 수 없습니다(409). 먼저 멈추고 비우세요.

이 화면이 쓰는 API

ProcessGroupFlowDTO pg = flow.getFlow("root", false).getProcessGroupFlow();
List<ProcessGroupEntity> children = pg.getFlow().getProcessGroups();

ProcessGroupEntity created = groups.createProcessGroup(new ProcessGroupEntity()
        .revision(new RevisionDTO().version(0L))
        .component(new ProcessGroupDTO().name("sdk-demo-group")
                .position(new PositionDTO().x(400d).y(0d))),
        parentId, null);

// 그룹 전체 시작/정지
flow.scheduleComponents(new ScheduleComponentsEntity().id(groupId)
        .state(ScheduleComponentsEntity.StateEnum.STOPPED), groupId);

// 삭제: 현재 revision의 version을 쿼리 파라미터로
ProcessGroupEntity current = groups.getProcessGroup(groupId);
groups.removeProcessGroup(groupId, current.getRevision().getVersion(), clientId, null);
