프로비넌스란?

NiFi는 FlowFile에 무슨 일이 있을 때마다 프로비넌스 이벤트를 남깁니다. 이벤트에는 시각, 컴포넌트, 그 시점의 속성(바뀌기 전 값 포함), 내용의 위치가 들어 있어 "이 데이터가 어디서 와서 어떻게 바뀌었나"를 추적할 수 있습니다.

종류예
CREATEgenerate가 FlowFile을 만듦
ATTRIBUTES_MODIFIEDtag가 env, source 속성을 붙임
DROP자동 종료되거나 큐 비우기로 지워짐
SEND / RECEIVE외부 시스템과 주고받음

검색은 비동기

검색 요청을 만들고(submitProvenanceRequest), finished가 될 때까지 조회한 뒤, 요청을 지웁니다. 컴포넌트로 거르려면 searchTerms의 키로 ProcessorID를 씁니다. 쓸 수 있는 키는 getSearchOptions()에 있습니다.

따라 해 보기

  1. 컴포넌트 tag로 검색합니다. ATTRIBUTES_MODIFIED 이벤트가 보입니다.
  2. 이벤트 id를 눌러 속성 표에서 env가 새로 붙은 것을 봅니다.
  3. 출력 내용으로 그 시점의 JSON 내용을 받습니다.

이 화면이 쓰는 API

ProvenanceEntity query = provenance.submitProvenanceRequest(new ProvenanceEntity()
        .provenance(new ProvenanceDTO().request(new ProvenanceRequestDTO()
                .maxResults(20).summarize(true).incrementalResults(false)
                .searchTerms(Map.of("ProcessorID",
                        new ProvenanceSearchValueDTO().value(processorId))))));
String id = query.getProvenance().getId();
try {
    while (!query.getProvenance().isFinished()) {
        Thread.sleep(250);
        query = provenance.getProvenance(id, null, true, false);
    }
    List<ProvenanceEventDTO> events = query.getProvenance().getResults().getProvenanceEvents();
} finally {
    provenance.deleteProvenance(id, null);
}
