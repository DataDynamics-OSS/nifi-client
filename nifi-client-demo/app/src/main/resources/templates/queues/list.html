연결·큐

연결(connection)은 프로세서 사이의 큐입니다. 흐름 전체의 큐 크기를 상태 API 한 번으로 읽고(recursive=true), 새 연결을 만듭니다. 연결을 누르면 큐 안의 FlowFile을 보고 비울 수 있습니다.

출발 → 도착큐사용률 (개수 / 크기)입력 / 출력 (5분)그룹
연결이 없습니다.

동작

연결 만들기 groups.createConnection

출발 프로세서의 관계(relationship) 중 무엇을 이 큐로 보낼지 고릅니다. 출발과 도착이 같은 그룹에 있어야 합니다. 프로세서끼리가 아니면(포트, 깔때기) ConnectableDTO.TypeEnum만 바꾸면 됩니다.
